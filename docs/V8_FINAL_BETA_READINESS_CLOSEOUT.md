- Final human review remains required.
- Beta feedback uses `mailto` only.

## Security Positioning (Current V8 Beta Posture)

- Full security/encryption hardening is not complete in V8.
- Security hardening is planned for Beta 1/post-beta once workflow requirements are stable.
